# Автоматизация администрирования отеля

Учебный проект по дисциплине «Разработка ПО».

## Команда

| Участник | Роль |
|---|---|
| Марк Арутюнов | Бэкенд, база данных |
| Егор Анохин | Фронтенд, дизайн |

## Технологии

- **Язык:** C#
- **СУБД:** Microsoft SQL Server Express
- **Архитектура:** клиент-сервер

## Структура репозитория

| Папка | Назначение |
|---|---|
| `docs/` | Документация и диаграммы |
| `db/` | Скрипты базы данных |
| `src/backend/` | Серверная часть |
| `src/frontend/` | Интерфейс |

## Ветки

- `main`: стабильная версия
- `backend`: разработка БД и серверной части
- `frontend`: разработка интерфейса
