# 🏨 Автоматизация администрирования отеля

Десктопное приложение для администратора отеля. Позволяет вести номерной фонд, бронирования, гостей и дополнительные услуги, а все данные хранятся в базе SQL Server.

---

## О проекте

Приложение помогает администратору отеля в повседневной работе:

- **Номера:** категории, цены и текущие статусы
- **Бронирования:** заселения, выезды и статусы броней
- **Гости:** база постояльцев с контактными данными
- **Услуги:** дополнительные платные услуги и их стоимость

## База данных

База **HotelDB** состоит из следующих таблиц:

| Таблица | Назначение |
|---|---|
| `ROOMS` | Номера отеля |
| `ROOM_CATEGORIES` | Категории номеров |
| `BOOKINGS` | Бронирования |
| `BOOKING_STATUSES` | Статусы бронирований |
| `BOOKING_SERVICES` | Услуги в рамках брони |
| `GUESTS` | Гости |
| `SERVICES` | Дополнительные услуги |
| `PAYMENTS` | Платежи |
| `USERS` | Пользователи системы |
| `ROLES` | Роли пользователей |
| `PASSWORD_CHANGE_LOG` | Журнал смены паролей |
| `ERROR_LOG` | Журнал ошибок |

## Запуск

**Что потребуется:** Windows, Visual Studio 2022, SQL Server Express и SSMS.

1. Склонировать репозиторий.
2. В SSMS подключиться к `localhost\SQLEXPRESS` и выполнить скрипты из папки `db/`.
3. Открыть решение в Visual Studio.
4. Указать свою строку подключения к базе:
   ```
   Server=localhost\SQLEXPRESS;Database=HotelDB;Trusted_Connection=True;TrustServerCertificate=True;
   ```
5. Нажать **F5**.
